Questions

Before you download

My antivirus says Soro is a virus. Is it?

No. Soro changes system settings, closes apps and cleans files, and automatic scanners (especially "machine learning" ones like Malwarebytes) flag new tools that do that. Soro isn't code-signed yet, which makes this more likely.

If your antivirus quarantines it, restore it and add the Soro folder to its allow list.

Windows says "Windows protected your PC".

That's SmartScreen, shown for any new app that isn't signed yet. Click More info, then Run anyway.

Can Soro break my PC?

Soro makes a System Restore point first and backs up every setting before it changes it. "Undo everything" on the Optimize page puts it all back. It never touches Windows Update, Windows Security, the Microsoft Store, Xbox, audio, Wi-Fi or Bluetooth.

Why is my ping high in the UAE?

Speed (like 1 Gb) and ping are different things. Fortnite's Middle East servers are in Doha, Qatar, so set Matchmaking Region to Middle East, use a cable instead of Wi-Fi, and close apps that download in the background. Soro's Ping Doctor checks all of this for you.

Does it work on laptops?

Yes. Power tweaks only apply while plugged in, battery-draining tweaks stay off, and Soro warns you about battery before gaming.

What do I need?

Windows 10 or 11 (64-bit). Nothing else to install - Soro is one small file.
